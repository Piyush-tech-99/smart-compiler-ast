# Smart Compiler AST Analyzer

**Smart Compiler AST Analyzer** is a web-based compiler analysis application designed to simplify and visualize the internal working of a compiler. It helps users understand how source code is processed through different compiler phases, including lexical analysis, syntax analysis, Abstract Syntax Tree (AST) generation, and semantic analysis.

By leveraging modern web technologies, the platform provides an interactive environment for analyzing source code and understanding compiler design concepts.

---

## Features

- **Lexical Analysis:** Breaks source code into meaningful tokens.
- **Syntax Analysis:** Analyzes the grammatical structure of source code.
- **AST Generation:** Generates an Abstract Syntax Tree representing the structure of the input code.
- **AST Visualization:** Displays the hierarchical structure of the generated AST.
- **Semantic Analysis:** Performs semantic checks on the source code.
- **Intermediate Code Generation:** Generates an intermediate representation of the source code.
- **Interactive Interface:** Provides a user-friendly web interface for submitting and analyzing code.

## Setup Instructions

1. Clone the repository:

   ```bash
   git clone https://github.com/Piyush-tech-99/smart-compiler-ast.git
   ```

2. Navigate to the project directory:

   ```bash
   cd smart-compiler-ast
   ```

3. Install backend dependencies:

   ```bash
   cd Backend
   npm install
   ```

4. Start the backend server:

   ```bash
   node server.js
   ```

5. Open another terminal and navigate to the frontend directory:

   ```bash
   cd frontend
   npm install
   ```

6. Start the frontend application:

   ```bash
   npm run dev
   ```

7. Open the local URL displayed in the terminal to access the application.
